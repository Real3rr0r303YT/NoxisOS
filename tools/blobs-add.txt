# Vendor files that newer Nothing OS versions need but that are still
# missing in the device tree's proprietary-files.txt. ./noxis.sh blobs adds
# them before the extraction - but only if the file really exists in the
# dump. On an older version that does not have it nothing happens.
#
# How to tell something is missing here: the build stops after seconds
# with   "X" depends on undefined module "Y"   - then Y.so belongs here.

# from the dump but from a rename entry 'source:target' in the device tree.
# If such a module is missing, the list is usually damaged (e.g. by --regen)
# - then reset proprietary-files.txt with 'git checkout' instead of adding
# something here.
